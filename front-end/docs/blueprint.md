# **App Name**: Krishi Sakhi - AI Farming Assistant

## Core Features:

- AI Voice Assistant: Voice-activated tool for querying farming advice and accessing app features.
- Disease Detection: Step-by-step tool for image-based plant disease identification using AI analysis.
- Crop Recommendation: AI powered suggestions for optimal crops based on soil analysis and weather data.
- Yield Prediction: Estimates crop yield based on historical data and current conditions using a tool.
- Multilingual Support: Provides a language toggle with JSON translation files for farmer-friendly access in multiple regional languages.
- Dashboard: Displays weather, location, and quick access to tools with a user-friendly card-based layout.
- Government Schemes: Provides a way for users to see available schemes in their region.

## Style Guidelines:

- Primary color: Deep green (#2F5D1E) to represent nature and growth, providing a calming and trustworthy feel.
- Background color: Very light green (#F6F7F3) to offer a clean and fresh appearance, ensuring comfortable readability.
- Accent color: Light green (#E9F2E3), a desaturated analogous color, is used for highlights to provide subtle visual cues.
- Headings: 'PT Sans' sans-serif font to ensure readability. Body: 'PT Sans' sans-serif font. 'PT Sans' is used for both headings and body text because it works well in either role, and the user prompt specified "No clutter."
- Lucide-React icons providing clear and consistent visual cues throughout the app, ensuring easy navigation and feature recognition.
- Card-based layout with rounded corners (2xl) and soft shadows for a modern, touch-friendly interface.
- Framer Motion is used to create smooth transitions, card hover effects, and button tap feedback for an engaging user experience.
